# Bird-Museum-Studies
Code to parse all scientific papers that use the keywords birds and museum specimens.
Publication records matching the terms “museum specimen*” AND “bird*”, “Aves”, or “avian” we downloaded from Web of Science, resulting in 1043 records (as of June 2026; publication dates ranged from 1930-2026).
R script to count museum usage - each author from each publication was counted as a separate event. From the citation information, we extracted the institutional addresses of each author and plotted the sum for each country.

For manuscript submitted to Ibis.
